# NILORA — Introductory Website

Responsive Arabic-first landing page introducing NILORA, its vision, planned capabilities, platform concept, target audience, and official links.

## Run locally
Open `index.html` in a browser. No build step is required.

## Project files
- `index.html` — page content and structure
- `style.css` — responsive layout and NILORA brand styling
- `script.js` — mobile navigation interaction
- `assets/nilora-mark.svg` — editable vector interpretation of the NILORA river/roots/leaf logo concept

## Brand palette
- Forest: `#2F3D28`
- Green: `#556D4A`
- Sage: `#A4AC86`
- Pale green: `#C8D5B5`
- Sand: `#D8C9A9`
- Cream: `#EDE8D9`
- Earth brown: `#A67C52`

## Notes
- Capabilities are presented as planned product direction; they should not be interpreted as confirmation that every feature is already implemented.
- The dashboard is an illustrative concept, not a live data dashboard.
- The SVG mark is a vector interpretation of the logo concept and can be replaced with the approved master logo asset.
- The site uses Google Fonts (Cairo and Manrope); a network connection is needed to load them.
